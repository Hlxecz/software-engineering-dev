1. 대상 제어기 선택

PC 기반 소프트웨어 작업 제어기로서 사용자의 명령에 따라 글의 입력·상태·저장·외부 전달을 관리하는 H.Dev Studio Java를 선택한다. 입력과 피드백이 분명하며 기존 화면·AI·발행 자산에 Java 저장 계층을 연결해 독립 앱으로 구축할 수 있다.

단계 목적: 제어 대상과 동작을 정의한다. 필수 내용: 대상·선정 이유·사용자·입력과 피드백.

항목 선택한 대상
사용자 사진과 메모로 자신의 블로그 글을 작성하는 개인
제어 대상 글 작업 상태, 자료 저장, AI 생성 요청, 검토한 초안의 발행 순서
환경 Windows PC의 Electron·Node.js 앱과 Java 저장 계층

해석: 기존 요구와 기준 커밋 5025a9d의 코드에서 도출한 제어 개념이다. 실제 프로그램의 상태 전이도를 뜻하지 않는다. 하드웨어 대신 글 작업을 제어하며, 실패는 성공과 구분하여 사용자에게 돌려준다.

구현 확인: 기준 커밋 5025a9d의 외부 연결 흐름. Codex/Claude Code CLI는 PC에서 별도 실행되는 도구이며 이 앱 경계 밖의 의존 대상이다. 제공사 계정이나 원격 AI 자체와 동일한 구성요소로 그리지 않았다. 전용 JSON·사진은 내부 관리 자료이며 원본 앱과 원본 GitHub 저장소는 운영 연동 대상이 아니다.
