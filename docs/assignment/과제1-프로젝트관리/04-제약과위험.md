# 4. 제약과 위험

[이전: 문맥과 이해관계자](03-시스템관계와이해관계자.md) · [목차](00-목차.md) · [다음: 규모와 시간 산정](05-규모와시간산정.md) · [통합 HTML](통합보고서.html#step-4)

**실행 환경·호환·파일 처리·외부 의존을 제약으로 확인하고, 실패 영향과 대응 업무를 연결한다.**

**단계 목적:** 지켜야 할 조건과 위험 대응을 조사한다. **필수 내용:** 환경·수치·저장/삭제 한계·외부 의존·자원·근거.

## 제약·위험 → 영향 → 대응

| 제약·위험 | 영향 | 대응·WBS | 근거 |
|---|---|---|---|
| Windows 64비트, 개발 Node 22 이상·JDK 17 이상. EXE도 Java 17 이상 별도 필요 | Java 누락·PC 차이로 빌드/저장/실행 실패 | 환경 확인 2.2, 실행 안내·EXE 시연 8.1–8.3 | [RUN](../RUN.md), [package](../../../package.json) |
| 직접 작성 Java 클래스 상한 30개, 현재 11개 | 무분별한 추가 클래스는 과제 범위 초과 | 책임 분리·개수 검사 2.2·7.1 | [PLAN](../PLAN.md) |
| 기존 화면·JSON/해시/경로 호환, 소스·자료 격리 | 재열기 실패·원본 자료 변경 위험 | 복사한 검사 자료의 필드·해시·옛 경로 대조 2.1·3.1–3.4·7.1 | [Workspace](../../../java-backend/src/main/java/com/hdev/assignment/workspace/Workspace.java) |
| 요청마다 동기 JVM 실행, timeout 30,000 ms·출력 버퍼 48 MiB 설정 | Node가 완료를 기다리고 실행 시작 비용 발생 | 요청/오류 규약·연결 확인 5.1·5.2. 수치를 응답 성능 실측으로 사용하지 않음 | [java-store](../../../scripts/java-store.mjs) |
| 같은 자료 폴더의 Java 요청끼리만 파일 잠금 | Node 쓰기를 포함한 앱 전체 동시성 보호는 아님 | 충돌 검사·오류 표시, 같은 자료의 동시 편집 회피 4.2·7.1 | [Main](../../../java-backend/src/main/java/com/hdev/assignment/bridge/Main.java) |
| 개별 파일 임시 기록 후 가능한 경우 원자적 교체, 미지원 시 일반 교체 | 여러 파일 전체의 트랜잭션·모든 실패 롤백을 보장하지 않음 | 파일 단위 오류와 영향 범위 기록 3.1·7.1 | [JsonFiles](../../../java-backend/src/main/java/com/hdev/assignment/common/JsonFiles.java) |
| 삭제 전 대상 경로/트리 검사, 삭제 중 OS 오류 가능 | 부분 삭제 가능, 전체 복구 보장 없음 | 지정 ID·다른 글 보존·실패 범위 확인 3.5·7.1 | [StorageService](../../../java-backend/src/main/java/com/hdev/assignment/post/StorageService.java) |
| AI CLI 설치/계정, 티스토리 로그인·DOM, 공개 웹·네트워크 의존 | 생성/조회/발행 중단 가능 | 로컬 수동 흐름, 모의 검사, 실제 외부 증거 구분 6.2·6.3·7.2 | [AI](../../../scripts/ai.mjs), [발행 연결](../../../desktop/publish.mjs) |
| 발행 제출 후 결과 불확실 시 자동 재시도 금지 | 확인 없이 재시도하면 중복 발행 위험 | 불확실 상태 유지·외부 결과 확인 6.3·7.2. 검사 글을 임의 공개하지 않음 | [publication](../../../scripts/publication.mjs) |
| 1인 주 20 h 가정, 요구/가용 시간 변화 | 기준 160 h 또는 10주 계획 초과 가능 | 순차 배분, 위험 예비 32 h, 범위/추정 갱신 9.1 | [WBS 데이터](계획자료/업무계획.json) |

자료 위치는 개발/웹 `%APPDATA%/H.Dev Studio Java Dev/workspace`, 배포 `%APPDATA%/H.Dev Studio Java/workspace`이며 재정의는 `HDEV_JAVA_DATA_DIR`만 사용한다. 원본용 `HDEV_DATA_DIR`를 사용하지 않고 기존 자료는 별도 복사본으로 가져온다.

## 코드의 입력 제한

| 입력 | 제한 값 | 근거 |
|---|---|---|
| 제목·메모 | 제목 200자, 메모 20,000자 | [server](../../../scripts/server.mjs) |
| 사진·첫 수동 보관 | PNG/JPEG/WebP, 파일별 10 MiB, 일반/표지 각각 목록 최대 20장. 처음 입력 사본 생성 시 사진 최소 1장 | [JobRepository](../../../java-backend/src/main/java/com/hdev/assignment/post/JobRepository.java), [SnapshotService](../../../java-backend/src/main/java/com/hdev/assignment/post/SnapshotService.java) |
| 참고자료 | 최대 5개, URL 2,048자, 붙여넣기 10,000자, 공개 HTTPS | [references](../../../scripts/references.mjs), [public-web](../../../scripts/public-web.mjs) |
| 지침 | 분류 지침 최대 10,000자, 기본 지침 1–20,000자 | [PromptService](../../../java-backend/src/main/java/com/hdev/assignment/prompt/PromptService.java), [StyleService](../../../java-backend/src/main/java/com/hdev/assignment/prompt/StyleService.java) |
| 발행 태그 | 최대 10개, 각 50자, 중복 거부 | [publication](../../../scripts/publication.mjs) |

입력/실행 설정을 조사한 값이며 최대 처리 성능 측정이 아니다. **revision**은 저장 충돌을 확인하는 버전 값, **JVM**은 Java 실행 환경, **DOM**은 브라우저 화면 요소 구조이다.
