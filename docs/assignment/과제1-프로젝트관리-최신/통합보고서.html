1. 대상 제어기 선택

단계 목적: H.Dev Studio Java를 블로그·프로젝트 기록의 글쓰기를 돕는 PC 기반 소프트웨어 작업 제어기로 정의한다.

항목 대상과 역할
주요 사용자 1 블로그를 작성하는 사람: 자료를 모아 글을 쓰고 검토·발행
주요 사용자 2 포트폴리오를 준비하는 학생: 프로젝트 경험을 활용 가능한 글 자료로 정리
주요 사용자 3 초안 구성이 어려운 사람: 메모에서 글의 흐름을 잡고 필요한 부분만 다듬기
제어 대상 재료·초안·다듬기·발행·기존 글 수정의 순서와 저장 상태
입력 메모·직접 쓴 글·참고자료, 선택한 사진, 지침과 사용자 명령
처리 입력 검사 → 작업 조정 → Java 보관 또는 외부 요청 → 결과 확인
피드백 로컬 저장·실패·충돌·원격 결과 불확실을 구분한 화면 안내
선정 이유 명령·처리·피드백이 분명하고, 실제 Windows 앱의 범위와 검수를 구체화할 수 있음

앱은 글 작업의 상태와 전달 순서를 관리한다. 로컬 보관과 원격 공개·수정은 별개이며, 공개 작업은 사용자가 선택한다.

2. 목표와 범위

단계 목적: 자료·메모에서 글의 구성과 초안을 잡는 부담을 줄이고, 학생의 프로젝트 경험을 포트폴리오에 활용할 글 자료로 정리하도록 지원한다.

목표 구분 우선하는 결과
사용자 목표 직접 작성·AI 초안·부분 다듬기를 선택하고, 보관한 글을 다시 열어 이어 쓰기
과제 구현 목표 기존 화면·AI·발행 자산을 재사용하면서 독립 Windows 앱의 실제 저장·관리를 Java로 통합

내부 책임

Node는 HTTP·AI·HTML·원격 작업을 조정하고 Java는 사용자 자료와 새 저장 상태를 관리한다.

3. 문맥과 이해관계자

단계 목적: 앱 전체를 하나의 시스템으로 묶고 외부 대상과 이해관계자의 요구를 구분한다.

주요 대상 사용자

사용자 목적 어려움 필요한 기능 기대 결과
블로그 작성자 경험·정보를 글로 발행 자료 분산·반복 편집 재료 정리·작성·검토·발행 보관한 글을 이어 쓰고 게시
포트폴리오 준비 학생 프로젝트 경험을 글 자료로 정리 과정·문제·결과의 구성 사진/메모·직접 작성·초안·재열기 포트폴리오에 활용할 프로젝트 기록
초안 구성이 어려운 사람 메모를 읽을 만한 초안으로 발전 빈 화면·문장 흐름·표현 AI 초안·부분 다듬기·되돌리기 검토·수정할 수 있는 자기 글

AI CLI는 PC에서 별도 실행되는 외부 도구이며 원격 AI 서비스 자체와 동일하지 않다. 전용 JSON·사진은 시스템 내부 자료이고, 이해관계자 요구는 사용 흐름에서 도출한 것으로 별도 인터뷰 결과가 아니다.

4. 제약과 위험

단계 목적: 실행·자료·검증의 한계를 확인하고 손실과 오작동을 줄이는 대응을 정한다.

지켜야 할 조건

제약 적용 기준
실행 환경 Windows x64, 개발 Node 22 이상·JDK 17 이상; EXE 실행에도 Java 17 이상 필요
자료·호환 전용 자료/세션, UTF-8·기존 JSON/해시 유지; 원본 대신 복사본으로 검사
입력 수동 작성은 사진 0장 허용, AI 초안 생성은 사진 필요; PNG/JPEG/WebP 사진별 10 MiB·일반/표지 각각 최대 20장
지침·분류 현재 카테고리 캐시는 블로그 1개, 분류 지침은 블로그별 보존; 저장 버전·번호·전체 경로 확인
실행·저장 경계 저장 요청마다 Java를 실행하므로 대기 비용이 발생; Java 요청끼리 잠금, 지정 파일의 요청 실패 복원은 강제 종료·전원 장애 복구가 아님
확인한 범위 임시 자료·모의 AI/편집기·격리 EXE로 확인; 실제 AI 계정 호출·공개 발행·원격 기존 글 저장은 실행하지 않음
