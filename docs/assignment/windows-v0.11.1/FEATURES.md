# Windows 기능 반영표

[최신 설계 목차](README.md)

원본 v0.11.1의 공통 기능과 Windows 실행부를 반영합니다. Mac 배포 스크립트·DMG·ZIP은 이 과제 범위에 포함하지 않습니다.

| 기능 | 현재 동작 | 담당 |
|---|---|---|
| 새 화면 | 다크·라이트 선택/복원, 오리 로고·반짝이, 움직임 줄이기, 내장 Pretendard | JS·CSS |
| Windows 창 | 1261×735 시작 창, 드래그 영역·창 버튼·메뉴, 자료 폴더 열기 | Electron |
| 글·사진 | 제목·메모·순서·참고자료, 사진 읽기·표지·보관함·용량·삭제 | Java 저장, JS 화면 |
| 입력 사본 | 기존 입력 해시 재사용·사진 무결성 확인, 텍스트 전용 ready/prepare | Java |
| 직접 작성 | 사진 없이 시작·보관·다시 열기 가능 | JS 편집·Java 저장 |
| AI 초안 | Codex/Claude 선택·로그인·진행 표시·민감 사진 제외; 생성에는 사진 필요 | JS CLI |
| AI 다듬기 | 한 칸·여러 칸·전체 선택, 공통/분류 지침 고정, 코드·사진·선택 외 내용 유지 | JS AI·검증 |
| 다듬기 보관 | 원문 digest 재검사, 결과·적용 지침·undo 동시 처리 | Java |
| 되돌리기 | 재실행 뒤에도 복원, 이후 본문 변경 시 거부, 현재 검토 메모 유지 | Java |
| 기존 글 가져오기 | 제목·태그·문단·표·코드·강조·링크·사진과 원문 형식 보존, 재사용·오프라인 열기 | JS 수집·정규화, Java 원문·매핑 저장 |
| 원문 형식 보호 | 외부 실행 HTML 제거, 편집 가능한 문장과 변경 불가 형식 틀 분리 | JS 공통 렌더러 |
| 기존 글 수정 | 같은 주소·글 번호에 반영, 제출 전 원문 재확인, 태그·사진·카테고리·발행 정보 보존 | JS·Electron |
| 수정 시도 보관 | 원본 초안 바이트·사진 해시 확인, 시도별 불변 사본·진행 상태·결과 기록 | Java |
| 원문 충돌 | 수정 전에 중단, 명시적 다시 불러오기로 원문/로컬 변경 합치기, 백업 내려받기 | JS 합치기, Java 백업 |
| 중복·실패 | 같은 결과 재전송 방지, 제출 전 실패/제출 후 불확실 구분, 자동 재시도 차단 | JS 조정·Java 기록 |
| 분류·프롬프트 | 카테고리 캐시, 기본·분류별 지침·충돌 검사, 개선된 5종 예시 | Java 저장·JS 예시/화면 |
| 기본 지침 갱신 | 알려진 구버전 기본값만 백업 후 갱신, 사용자 수정본·별도 경로 보존 | Java |
| 미리보기 | 목차·표지·팁/주의·표·GitHub 카드·기존 글의 연속 문서 편집 | JS |
| 로그인 | 원본 앱과 다른 영구 세션, 소유 블로그 선택·계정 변경·실패/취소 처리 | Electron |
| 참고자료·공개 글 | 웹·노션·붙여넣기, 공개 목록·검색·카테고리 필터 | JS 수집·Java 글 자료 저장 |
| 실행·배포 | Windows 실행 스크립트, JDK 17 저장 모듈 빌드, EXE에 JAR/Gson/글꼴·라이선스 포함 | Node·Electron·Java |

모든 파일 쓰기를 Java로 옮긴 것은 아닙니다. `preview.html`·`render.json` 같은 파생 미리보기, AI 임시 파일·AI 선택 설정, 원격 글 목록 캐시, 기존 새 글 발행 모듈의 전송 기록은 JS에 유지합니다. 사용자가 편집하는 글·사진·초안과 새 기능의 원문·undo·충돌 백업·수정 시도 기록은 Java가 관리합니다.
