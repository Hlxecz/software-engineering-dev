## 기능·언어·클래스 역할

[PLAN.md](PLAN.md)의 전체 기능과 [ARCHITECTURE.md](ARCHITECTURE.md)의 11개 클래스 구조를 유지합니다. 화면·Electron·AI CLI·티스토리 연결은 JavaScript가, 글·초안·사진·카테고리·기본 및 분류별 프롬프트 저장과 관리는 실제 Java가 담당합니다. 기능별 패키지와 원본 앱 자료 격리도 유지합니다.

## 반영과 검증 계획

1. 네 Electron 검사에 원본의 연결 종료 수정을 그대로 적용합니다.
2. package·lock·Java IDE 버전, 변경 내역, 실행·발표 문서를 `0.7.4-java.1`에 맞춥니다.
3. 전체 자동 검사와 변경된 Electron 검사, Windows EXE 빌드·실행을 확인합니다.
4. 포함된 실행 코드와 Java JAR를 대조하고 별도 임시 자료로 실제 EXE의 저장·불러오기·삭제를 검사합니다. 실제 AI 생성·공개 발행은 하지 않습니다.

결과는 [VERIFICATION.md](VERIFICATION.md)에 기록합니다.
