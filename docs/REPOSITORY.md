# 과제 저장소 구성과 출처

이 저장소는 `H.Dev Studio Java 0.7.4-java.1`의 코드와 과제 문서를 별도 폴더로 복사한 제출용 저장소입니다. 2026년 10월 14일 새 Git 이력으로 시작하며 원본 저장소에는 연결하지 않습니다.

## 재사용한 부분

- 원본: [Hlxecz/blog-automation](https://github.com/Hlxecz/blog-automation), v0.7.4
- 원본 릴리스 기준: `2017f6a6763292a13cb5685928ca1523596ffde9`
- 기존 Java 과제 구현 기준: `5025a9d69218e72bd27fc0ce8f0975fa5c0acd83`
- 기존 화면, Electron, AI CLI, 티스토리 연결을 활용했습니다.
- 글·사진·초안·카테고리·프롬프트 파일 관리는 Java 11개 클래스로 옮겼습니다.

위 커밋은 출처를 식별하는 값입니다. 새 저장소는 원본 Git 이력을 복사하지 않아 해당 커밋으로 체크아웃할 수 없습니다. 기존 문서의 `upstream-v0.7.4`·이전 커밋 비교 명령도 당시 로컬 검사 기록입니다.

## 이번 정리

실행 경로와 문서 링크를 보존하기 위해 `web`, `desktop`, `scripts`, `java-backend`의 이름을 유지했습니다. README와 문서 목차에서 코드·검사·도구·제출 자료를 분리해 안내합니다. 앱 코드의 동작은 변경하지 않았습니다.

README에 구조, 실제 11개 클래스 관계, 초안 저장 시퀀스와 유스케이스 그림을 넣었습니다. 기존 설계 그림 49개와 26쪽 제출 PDF도 포함합니다. 보고서의 이름·학번·전공·제출일은 학교 제출본과 같습니다.

## 포함하지 않는 파일

- 원본 `.git` 및 이전 Git 이력
- 사용자 사진·초안·말투 자료와 블로그·AI 개인 설정
- 로그인 쿠키·인증 토큰·환경 파일
- `node_modules`, `.runtime`, `graphify-out`, `dist`, 렌더 세션
- Java 생성 클래스·JAR 및 다운로드된 라이브러리

Gson은 빌드 시 고정 버전·해시로 다운로드합니다. [외부 라이브러리 안내](../java-backend/THIRD-PARTY.md)와 [Gson 라이선스](../java-backend/LICENSE-gson.txt)를 포함합니다. 원본 코드에 없는 라이선스를 새로 부여하지 않습니다.
